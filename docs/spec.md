# 生活リズム記録アプリ 開発仕様書

## 概要と前提

iPhone のホーム画面に追加して使う、生活リズムの記録ウェブアプリを作る。記録は診察で医師に見せるためのもので、アプリで診断や判定は行わない。

- 記録する人：本人1名(iPhone、Safari)
- 閲覧する人：本人と、本人が許可した家族1名(第2弾から)
- 公開場所：GitHub Pages(公開リポジトリ)。記録データはリポジトリにもサーバーにも入れない(第2弾の共有分を除く)
- 記録項目は医師とのすり合わせで変わる前提。項目は設定データとして持ち、プログラムを直さずに追加・変更・非表示ができる作りにする
- 保守はAI(Claude Code)で行う前提のため、一般的で情報の多い技術を選び、型と自動テストで壊れにくくする

## 開発の段階

第1弾は本人の iPhone だけで完結する範囲に絞り、外部への送信は一切しない。第2弾以降に必要なデータは、第1弾の時点から保存しておく。

| 段階 | 範囲 | 外部送信 |
| --- | --- | --- |
| 第1弾 | 記録画面、睡眠の記録、グラフ、記録の修正、1日の区切り時刻の設定、項目の非表示、CSV・PDF書き出し、JSONバックアップと復元 | なし |
| 第2弾 | 家族への共有(記録の有無と使われ方)、共有のオン・オフ、家族用の閲覧画面 | 本人が許可した範囲のみ |
| 第3弾 | 項目のカスタマイズ画面(本人が項目を追加・並べ替え)、項目ごとの共有設定(中身の共有) | 本人が許可した範囲のみ |

## 技術構成

| 用途 | 採用する技術 |
| --- | --- |
| 言語 | TypeScript |
| 画面 | React + Vite |
| ホーム画面アプリ化 | vite-plugin-pwa |
| 端末内保存 | IndexedDB(Dexie.js 経由) |
| グラフ | Apache ECharts |

GitHub Pages はリポジトリ名の下の階層で公開されるため、Vite の公開パス(base)をリポジトリ名に合わせる。

## 画面と記録の操作

第1弾の画面は5つ。下部のタブで切り替える。

| 画面 | 内容 |
| --- | --- |
| きょう | 「睡眠を記録」の大きなボタン、今日の睡眠の一覧(1件ごとに「修正」ボタン)、今日の項目の入力欄 |
| 振り返り | 睡眠と気分のグラフ、期間の切り替え(1週間・4週間・任意の期間) |
| 記録の一覧 | 日ごとの記録の確認、修正、追加、削除 |
| 書き出し | CSV書き出し、PDF用レポート、JSONバックアップと復元 |
| 設定 | 1日の区切り時刻、項目の表示・非表示、アプリの説明 |

睡眠の記録:

「寝る」「起きた」のボタンを押した時刻は、実際に眠った・目が覚めた時刻とは違うため、睡眠は時刻を選んで記録する。

1. きょう画面の下に「睡眠を記録」の大きなボタンを置く。押すと「眠った時刻」と「起きた時刻」を選ぶ画面を出す。初めの値は、起きた時刻が今(5分単位)、眠った時刻がその7時間前。1日に何回でも記録できる。
2. 起きた時刻は眠った時刻より後で、今より前にする。
3. きょう画面の「今日の睡眠」に、記録した睡眠を1件ずつ出し、横に「修正」ボタンを置く。修正画面では時刻の変更と削除ができる。
4. 前の日の分の睡眠(区切り時刻より前に眠り始めたもの)でも、今日の区切り時刻より後に起きたものは「前の日の分」と添えて「今日の睡眠」に出す。朝に記録した夜の睡眠をすぐ直せるようにするため。
5. 記録し忘れた睡眠は、記録の一覧から後で追加・修正・削除できる。
6. 「今日は何回に分けて寝ましたか?」を0・1・2・3回以上から選べる欄を、きょう画面にいつでも出す。記録の回数と違う場合は、その場で睡眠を追加できる。

その他の項目はタップ、選択肢、スライダーで入力し、文字入力は一言メモだけにする。入力した時刻は自動で記録し、後から修正できる。

## 初期の項目定義

中心項目は非表示にできない。任意項目は設定画面で非表示にできる。睡眠は専用の仕組み(睡眠の記録)で扱い、項目定義には含めない。

| 項目 | 入力タイプ | 選択肢・範囲 | 時間帯 | 中心/任意 |
| --- | --- | --- | --- | --- |
| 睡眠の回数(自己申告) | 単一選択 | 0回 / 1回 / 2回 / 3回以上 | なし | 中心 |
| 活動量 | 単一選択 | ほぼ動けず / ふつう / 活発 | 朝・昼・夜 | 中心 |
| 気分 | スライダー | −3〜+3、刻み1、0がふつう | なし(1日に複数回可) | 中心 |
| 気分の補足 | 複数選択 | いつもより少し軽い / いつもより元気すぎる / イライラが強い / 考えが次々浮かぶ / 眠らなくても平気だった / 衝動的に買い物をした | なし | 任意 |
| 服薬 | チェック | 服薬した | なし | 任意 |
| 食事 | チェック | 食べた | 朝・昼・夜 | 任意 |
| 外出 | チェック | 外出した | なし | 任意 |
| 人と話した | チェック | 話した | なし | 任意 |
| 一言メモ | 一言メモ | 自由記述(必須にしない) | なし | 任意 |

項目の文言と構成は医師とのすり合わせで変わる。変更はこの初期値と移行処理で行い、過去の記録は消さない。

## 1日の区切りとグラフ

記録には「何日の記録か」を保存せず、正確な日時だけを保存する。どの日に属するかは表示するときに区切り時刻から計算するため、区切り時刻をいつ変えても過去の記録がすべて新しい区切りで並び直る。

- 区切り時刻は設定画面で15分単位で変更できる。初期値は 4:00
- 区切り時刻を変えても、保存済みのデータは書き換えない
- 睡眠は開始時刻が属する日に振り分ける(区切り時刻をまたぐ睡眠を2日に分割しない)
- 区切り時刻の変更履歴を残し、グラフの期間内で変更があった場合は注記を出す
- 「今日は何回に分けて寝ましたか?」の回答も入力日時で保存し、表示時に日へ振り分ける

振り返り画面のグラフ：

| グラフ | 形 | 見たいこと |
| --- | --- | --- |
| 睡眠時間 | 日ごとの積み上げ棒。1日の中の1回目・2回目・3回目…を色分けして積み上げる | 1日の睡眠の合計と、何回に分かれたか |
| 睡眠の時間帯 | 日ごとの横棒。区切り時刻から24時間の帯に、眠っていた時間を塗る。色は積み上げ棒と同じ回ごとの色 | 寝る時刻のずれや分散 |
| 気分と睡眠 | 上に気分(−3〜+3)の点と折れ線(記録したすべての点を時刻の位置に置く)、下に睡眠時間の合計の棒。日付の位置をそろえて上下に並べる(目盛りを2本にしない) | 睡眠と気分の波の関係 |

回ごとの色は、1回目・2回目・3回目・4回目以降の4色で固定し、どのグラフでも同じ色を使う。色の違いだけに頼らないよう、凡例とタップ時の詳細(時刻と長さ)も表示する。終了していない睡眠はグラフでは薄い色で表示する。

## データの設計

「項目の定義」と「記録」を分けて保存し、項目の追加・変更はデータの追加だけで済む形にする。

- すべてのデータに UUID の id、作成日時、更新日時を持たせる
- 削除は「削除日時」を入れるだけにし、実際には消さない
- 日時はすべて UTC の ISO 形式で保存し、表示時に日本時間へ変換する
- データの形を変えるときは、保存形式のバージョンを上げて移行処理を書く

| 保存先 | 主な内容 |
| --- | --- |
| 項目の定義 | id、表示名、入力タイプ、選択肢、並び順、中心項目か、表示・非表示、共有の初期値(初期は共有しない)、時間帯の区切り(朝・昼・夜を分けて入力するか)、1日に何回も記録できるか(気分など。できない項目は同じ日・時間帯の記録を上書き) |
| 項目の変更履歴 | どの項目を、いつ、どう変えたか(追加、名前の変更、非表示、再表示) |
| 睡眠 | id、開始日時(眠った時刻)、終了日時(起きた時刻。前の版で「寝る」だけ押した記録は空)、開始の記録方法、終了の記録方法 |
| 記録 | id、項目の id、対象日時、値、時間帯(朝・昼・夜、該当する項目のみ)、記録方法 |
| 設定 | 1日の区切り時刻とその変更履歴、最後にバックアップした日時、保存形式のバージョン |

入力タイプは、チェック、単一選択、複数選択、スライダー(最小・最大・刻みを指定)、数値、一言メモの6種類。

記録方法は「その場で記録した」(きょう画面から)「後から追加した」(記録の一覧から)「後から修正した」の3種類。第2弾で家族に共有する「使われ方」の情報は、この記録方法と回数から作る。

## 書き出しとバックアップ

| 種類 | 用途 | 内容 |
| --- | --- | --- |
| CSV(睡眠) | 医師や家族が表計算ソフトで見る | 1行1回の睡眠。日付(区切り時刻で計算)、何回目か、開始、終了、長さ(分) |
| CSV(項目) | 同上 | 1行1件の記録。日付、時刻、時間帯、項目名、値 |
| PDF | 診察で見せる・渡す | 期間を選んだレポート画面を印刷用に整え、iPhone のプリント機能で PDF にする。3つのグラフ、日ごとの一覧、期間中の区切り時刻を載せる |
| JSON バックアップ | 機種変更、データ消失への備え | すべてのデータ(項目の定義、変更履歴、睡眠、記録、設定)と保存形式のバージョン |

- 書き出したファイルは iPhone の共有シートから保存・送信できるようにする
- CSV は Excel で文字化けしないよう、UTF-8(BOM付き)で出力する
- 書き出す期間は選べるようにする。日付の区切りは書き出し時点の区切り時刻を使い、ファイル内に明記する
- 一言メモを書き出しに含めるかは、書き出しのたびに選べる(初期は含めない)
- JSON の復元では、バージョンが古いデータも移行してから読み込む。復元前に、今のデータが上書きされることを確認する
- 最後のバックアップから14日たったら、きょう画面に控えめな案内を出す

## 守るルール

操作：
- 1日の記録は1分ほどで終わる量にする。文字入力は必須にしない
- ボタンは大きく、片手で押せる位置に置く
- 入力はすぐ保存し、「保存」ボタンを押させない
- すべての記録は後から修正・追加できる

表示：
- 記録がない日は空白のまま表示する。連続記録の日数、達成率、途切れの警告など、責める表示は出さない
- 文言は短く、やさしい言葉にする
- 診断、判定、危険度の表示はしない
- 設定画面に「医師に見せるための記録で、診断のためのアプリではない」「強く落ち込んだときは、アプリで様子を見ずに主治医や支援機関に連絡を」と載せる

プライバシー：
- 第1弾では外部への通信を行わない。アクセス解析、広告、外部フォントの読み込みも使わない
- 名前、診断名、薬の名前を入力させる欄は作らない
- アプリ名とリポジトリ名に病名を含めない
- 記録データ、書き出したファイルをリポジトリにコミットしない

- [ ] きょう画面の睡眠の「修正」ボタンから、時刻を直したり削除したりできる

- [ ] 区切り時刻を 4:00 から 8:00 に変えると、過去のグラフが並び直る。元に戻すと元の表示に戻る
- [ ] 睡眠時間のグラフで、同じ日の1回目・2回目・3回目が別の色で積み上がる
